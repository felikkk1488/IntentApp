# Приложение «Контактная книга»

**Разработчики:**
Максумов А.М. (ИП-23-3)
Синицын Р.В. (ИП-23-3)

## Описание
Приложение предоставляет быстрый доступ к контактам компании: звонок, email, адрес на карте и возможность поделиться контактом.

## Функциональность
Основной экран содержит:
- «Позвонить» — набор номера +7 (495) 123-45-67
- «Написать email» — открытие почты с темой «Обращение»
- «Показать офис на карте» — координаты 60.0237, 30.2289
- «Поделиться контактом» — отправка контакта через любое приложение
